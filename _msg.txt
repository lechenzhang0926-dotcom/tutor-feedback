fix(autostart): switch to scheduled task, make installers ASCII-only

Root cause of the failed autostart check: the machine had not actually
rebooted since 10/22 (uptime 2 days), so no startup mechanism had ever
been exercised. The site was down because the server process had been
stopped during testing, not because autostart failed.

Changes:
- install-autostart.ps1: also renames the Startup-folder .vbs to
  .disabled, so the scheduled task is the single entry point
- install-autostart.bat / .ps1: converted fully to ASCII. cmd.exe and
  PowerShell 5.1 read BOM-less UTF-8 as ANSI; CJK text was proven to
  break batch parsing and script syntax in this project.
- All four launcher/installer scripts verified ASCII-only.

Scheduled task runs as SYSTEM in session 0: starts at boot, no login
required, no visible window, auto-restart on failure.
