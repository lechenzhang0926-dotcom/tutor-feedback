# PDF 批量下载器 — Microsoft Edge 扩展

一键检测并批量下载当前网页中的所有 PDF 文件。

## 功能

- **智能扫描** — 自动检测页面中的 PDF 链接（支持 `<a>`、`<embed>`、`<iframe>`、`<object>`、`onclick`、`data-*` 等）
- **批量下载** — 勾选你需要的 PDF，一键全部下载
- **搜索过滤** — 输入关键词快速筛选文件名或 URL
- **全选 / 反选** — 快速切换选择状态
- **下载进度** — 实时显示每个文件的下载状态
- **并发控制** — 最多同时下载 3 个，避免浏览器卡死
- **完成通知** — 全部下载完成后弹出系统通知

## 安装方法

1. 打开 Microsoft Edge，地址栏输入 `edge://extensions/`
2. 打开左下角 **"开发人员模式"** 开关
3. 点击 **"加载解压缩的扩展"**
4. 选择 `pdf-downloader-extension` 文件夹
5. 扩展图标会出现在工具栏，点击即可使用

## 使用方法

1. 打开包含 PDF 链接的网页
2. 点击工具栏中的扩展图标（红色 PDF 图标）
3. 弹窗会自动扫描当前页面的 PDF 链接
4. 勾选需要下载的文件（默认全选）
5. 点击 **"下载选中"** 按钮
6. PDF 文件会保存到浏览器默认下载目录

## 文件结构

```
pdf-downloader-extension/
├── manifest.json      # 扩展配置（Manifest V3）
├── popup.html         # 弹窗界面
├── popup.js           # 弹窗交互逻辑
├── content.js         # 内容脚本：扫描页面 PDF
├── background.js      # 后台服务：下载管理
└── icons/             # 扩展图标
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 注意事项

- 需要 **"下载"** 权限才能保存文件
- 部分网站可能通过 JavaScript 动态加载 PDF，如果扫描不到，可以尝试刷新页面后再扫描
- Blob URL 和 Data URL 类型的 PDF 暂不支持批量下载（需要通过页面自身的下载按钮）
